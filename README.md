# talenty-flyers
Code-rendered recruitment flyers for Talenty job ads (Python/PIL), plus the rendered PNGs used as Meta ad creatives.

`out/<role-slug>/` holds the four sizes per role. `make_flyers.py` and `motif_options.py` are the scripts for the most recent role; the shared renderer they import (`flyer_common.py`) is kept outside this repo.
